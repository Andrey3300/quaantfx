## A. Баги текущей однофайловой версии

### Логика / функциональность
- [x] **A1.** Открытые сделки **неактивного** счёта не закрываются: `settleTrades()` обходит только сделки текущего счёта (`getTrades()`). Открыл сделку на демо → переключился на реальный → демо-сделка «зависает» и закрывается с опозданием в момент возврата на демо. — исчез: сервер закрывает все сделки сам, на обоих счетах.
- [ ] **A2.** Время жизни сигнала не связано с его экспирацией: `closeTime = now + SIGNAL_EXP[2](=300с) + random*120` всегда ~5 минут, даже у сигнала на 30 секунд.
- [ ] **A3.** «Случайный» интервал генерации сигналов на деле фиксированный: `setInterval(generateSignal, 18000+Math.random()*14000)` — рандом вычисляется один раз при старте.
- [ ] **A4.** Спиннер экспирации: нет заимствования при уменьшении. На `01:00:00` кнопка «−» у минут/секунд ничего не делает (упирается в 0); секунды занимают только у минут, но не у часов.
- [ ] **A5.** После `logout()` в шапке показывается `$0.00`; выбранный счёт (демо/реальный) не запоминается — после входа всегда сброс на демо.
- [ ] **A6.** Профиль: поля со звёздочкой (Имя, Фамилия, Дата рождения) помечены обязательными, но `saveProfile()` сохраняет их пустыми — валидации нет.
- [ ] **A7.** MACD: `v||0` заменяет пропуски нулями при расчёте сигнальной линии → начало линии искажается; на пустых данных границы масштаба улетают в `Infinity`.
- [ ] **A8.** Избранное нельзя править без логина (`persist()` делает early return при `U===null`) — звёздочки молча не сохраняются.
- [ ] **A9.** «Купить/Продать» и «Скопировать сигнал» без логина открывают окно входа, но после входа сделка не исполняется — нужно жать заново.
- [x] **A10.** Кнопка «Загрузить документы» (верификация) ничего не загружает — просто ставит статус «На проверке». Файлы не прикладываются вообще. — фронт загружает до 4 файлов (до 8 МБ), админ их смотрит.

### Производительность
- [ ] **A11.** Саб-панели индикаторов: `resizeSubPanels()` дёргается **каждый кадр** (60 fps) и пересоздаёт canvas-буферы; все индикаторы (SMA/EMA/BB/RSI/MACD/Stoch/Mom/CCI) пересчитываются каждый кадр без кэширования.
- [ ] **A12.** Список открытых сделок полностью перестраивается в DOM каждую секунду (сбрасывается hover, лишняя нагрузка).
- [ ] **A13.** Весь «бэкенд» в localStorage (включая base64-аватар) перезаписывается при каждом изменении, в т.ч. каждую секунду при закрытии сделок.

### Косметика / мелочи
- [ ] **A14.** Цена входа берётся из «сырого» тика, а линия цены на графике сглаженная (`smoothPrice`) — маркер новой сделки может чуть не совпадать с линией цены.
- [ ] **A15.** `chart-clock` показывает локальное время с подписью `UTC±X` (если задумывался UTC — неверно; если локальное — подпись сбивает).
- [ ] **A16.** `money()` форматирует отрицательные как `$-5.00` вместо `-$5.00` (видно в «Чистый результат» в истории).
- [ ] **A17.** `confirmDeposit()` принудительно переключает на реальный счёт → двойной тост («Зачислено» + «Переключено на реальный счёт»).
- [ ] **A18.** «Активные сессии» в профиле захардкожены: фейковая мобильная сессия всегда «3 дня назад».
- [ ] **A19.** Canvas использует `bold`-начертания, хотя JetBrains Mono загружен только 400–600 (жирность синтезируется браузером).
- [ ] **A20.** Нет favicon (404 в консоли).
- [ ] **A21.** Подпись «закрытие» у маркера экспирации может накладываться на саму плашку при малой высоте графика.
- [ ] **A22.** Мёртвый код: параметр `big` в `setAvatarEl(el, big)` не используется.
- [ ] **A23.** В карточке сигнала показывается сумма **пользователя** (`tradeAmount`), а не «трейдера» — выглядит как данные сигнала, но это локальная настройка.

### Безопасность (уходит само при переходе на бэкенд, но зафиксировано)
- [x] **A24.** Пароли хранятся в открытом виде в localStorage. — решено: только хеши (bcrypt), фронт подключён к API.
- [x] **A25.** «Сессия» — просто флаг в localStorage, никакой реальной аутентификации. — решено: токены-сессии в БД, httpOnly-куки; фронт работает через них.
